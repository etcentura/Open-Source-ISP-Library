## Text Elements
Gamma correction is the age processing operation based on the equation:
s = c*r^gamma, where "c" is a constant, "r" is the value of brightness for the original
pixel and "gamma" is the exponent used to edit the original pixel value.

Sometimes constant epsilon is added to deal with the zero-based shifts produces by
the calculations inmperfection, so the formula will be
s = c*(r+epsilon)^gamma

So the function for all of this stuff will look somehow like the presented ones below, where y - is the gamma value ^WT9CFizY

S ^nWliyONa

R ^wyecqGDj

L-1 ^XGH4RyVh

L-1 ^FGSu59u8

Feature 1.1 ^gBHDEz4M

y = 0,04 ^97QRXmv2

y = 0,40 ^OSjPrL0E

y = 1,00 ^kdki8G7N

y = 1,50 ^mCiCVrtY

y = 10,00 ^JcUhfZBQ

It's a notable fact, based on math above:
the more the gamma is, the lower the 
graph of the function

However, such mathematical operation as power is kinda
complicated for the computers, embeeded systems etc.

Therefore the module will be represented as a pre-calculated
(during the synthesis) LUT, containing the values correlated to
the original pixel brightness values.

It's supposed that there is no use of the costants "c" and "epsilon" to be used during the
calculations, so the formula will be just as s = (r)^gamma (assuming that all the 
non-zero level shifts handeled somewhere outside the module)
 ^wBz2FNuf
