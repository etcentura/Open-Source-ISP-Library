## Text Elements
Image cutter is a module not to resize image or find ROI, but to get the slice of pixels value to be spectated.
The main concept is demonstrated below, where the L = 2**Number_of_bits_per_pixel.
So there are some of the usage variants below. ^LeuXHy0X

S ^99LuhnBd

R ^AUcgrigW

L-1 ^GIqcOBQ8

L-1 ^Ij9G0vXY

S ^eNsTKsMX

R ^weUzeoRy

L-1 ^j3O8VQNS

L-1 ^X08kY5ax

Selected values to be clipped out by range and to
the targeted value ^cWu2uDU2

Values to be supressed by 
range and to the desired value ^pd9P8Tk2

Values to be bypassed by 
range and to the desired value ^4TCa1t2Z

So, the CSR registers should include these fucntions:

1) Total bypass to let stream of the pixels be untouched while going through the module
2) If there's no total bypass enabled, then decide whether to bypass untouched pixels of not (local bypass)
3) If there's no total bypass neither the local one, decide which value sould untouched pixels be supressed to
4) Select the range to clip
5) Decide which value should be the selected range clipped to ^HeOnnNFP
